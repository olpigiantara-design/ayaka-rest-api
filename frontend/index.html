Frequently Asked

Quick answers to common questions.

What is AYAKA REST API? +
A developer platform for generating and managing personal API keys that access our REST endpoints securely.
How do I get an API Key? +
Create a free account, open your dashboard, go to "My API Keys" and click "Generate API Key".
Is the API free? +
Yes. Free forever with 60 requests/minute per key. No credit card required.
How do I use the API? +
Send an HTTP request to any endpoint with the header X-API-Key: YOUR_API_KEY. See our documentation for full details.
Can I generate multiple API Keys? +
Yes. You can have up to 10 active keys at any time — perfect for separate projects or environments.
Is my API Key secure? +
Your key is hashed (SHA-256) in our database. We never store plaintext keys. The full key is shown exactly once at creation — save it then.
