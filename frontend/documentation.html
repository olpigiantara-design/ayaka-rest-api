Introduction

AYAKA REST API is a developer platform for generating and using personal API keys to access our REST endpoints. All endpoints return JSON and require authentication via the X-API-Key header.

Base URL: https://your-domain.vercel.app

Getting Started

  1. Create a free account at register.html
  2. Log in and go to your dashboard → My API Keys
  3. Click "Generate New Key" and copy it
  4. Use it in the X-API-Key header of requests

Authentication

Every request to /api/v1/* must include the header:

X-API-Key: ayaka_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Keys are hashed (SHA-256) at rest. Revoked keys return HTTP 403.

Generate API Key

Navigate to your dashboard, click My API Keys, then Generate New Key. The full key is displayed only once.

Endpoints

GET /api/v1/example

Connectivity / health check.

{
  "success": true,
  "creator": "Ayaka REST API",
  "message": "API connected successfully",
  "data": { "status": "online" }
}

GET /api/v1/user

Returns metadata about the API key owner.

GET /api/v1/keys/info

Returns metadata about the current API key.

Request Headers

X-API-Key: ayaka_live_xxx   (required)
Content-Type: application/json (optional)

Response Format

All successful responses include "success": true. Errors include "success": false and a message.

Error Codes

StatusMeaning
200Success
401Missing or invalid API key
403Key revoked or account disabled
404Endpoint not found
429Rate limit exceeded
500Internal server error

Rate Limits

Each API key is limited to 60 requests per minute. Exceeding this returns HTTP 429.

cURL Example

curl -X GET 'https://your-domain.vercel.app/api/v1/example' \
  -H 'X-API-Key: YOUR_API_KEY'

JavaScript Example

const response = await fetch(
  "https://your-domain.vercel.app/api/v1/example",
  {
    method: "GET",
    headers: { "X-API-Key": "YOUR_API_KEY" }
  }
);
const data = await response.json();
console.log(data);

Python Example

import requests

url = "https://your-domain.vercel.app/api/v1/example"
headers = {"X-API-Key": "YOUR_API_KEY"}

response = requests.get(url, headers=headers)
print(response.json())
